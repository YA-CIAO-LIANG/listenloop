# Subtitles for the Blender open-movie materials (D118)

English subtitles of the full films, as published on Wikimedia Commons,
used to make the official YouTube materials (`lib/blender-films.ts`,
`npm run blender:drafts`). The dialogue belongs to the films; the subtitle
pages' text is under CC BY-SA 4.0 (Wikimedia Commons). Each file's timing
matches the film's official upload on YouTube (same length to the second).
