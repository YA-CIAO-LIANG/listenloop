「連音」是英文聽力最大的坑：每個字單獨念都聽得懂，連在句子裡就認不出來。這篇整理最常見的五種規則，每一種都附例句與練法。

## 規則 1：子音＋母音，黏在一起

前一個字以子音結尾、下一個字以母音開頭時，子音會「移」到下一個字：

| 寫法        | 聽起來像    |
| ----------- | ----------- |
| turn it off | tur-ni-toff |
| an apple    | a-napple    |
| pick it up  | pi-ki-tup   |
| look at it  | loo-ka-tit  |

**聽寫技巧**：聽到一個怪字，試著從中間切開，看看是不是兩三個熟悉的字。

## 規則 2：相同的子音，只念一次

前一個字的結尾和下一個字的開頭是同一個（或很像的）子音時，只念一次，稍微拉長：

- bus stop → bu-stop
- good day → goo-day
- want to → wan-to

## 規則 3：t 和 d 的變化

美式英文裡，夾在母音中間的 t 常變成很輕的「d」音（閃音）：

- water → wa-der
- a lot of → a-lo-dof
- get it → ge-dit

句尾的 t 有時幾乎不發音：_Wait!_ 的 t 只剩一個停頓。

## 規則 4：縮讀：wanna、gonna、gotta

| 原本     | 口語  | 什麼時候會變                                     |
| -------- | ----- | ------------------------------------------------ |
| want to  | wanna | 後面接**動詞**：I want to go → I wanna go        |
| going to | gonna | 後面接**動詞**：I'm going to eat → I'm gonna eat |
| got to   | gotta | I've got to leave → I gotta leave                |

**注意**：後面接地點或名詞時不會變。_I'm going to the library_ 不會說成 gonna the library。

## 規則 5：did you、would you、don't you

y 開頭的 you 會和前面的 d、t 結合：

- did you → di-dʒu（「迪久」）
- would you → wu-dʒu
- don't you → don-tʃu（「咚丘」）
- got you → go-tʃa

## 怎麼練：先聽寫、再跟讀

1. **聽寫**一段 1～3 分鐘的英文，把聽不出來的地方標出來。多數會是上面這五種規則。
2. 對照原文，找出是哪一種連音。
3. **跟讀**同一段：自己念出連音，耳朵會更快認得。
