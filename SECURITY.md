# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

- Preferred: GitHub's private reporting, on this repository's **Security** tab → **Report a vulnerability**.
- Or the site's feedback page: <https://listenloop-three.vercel.app/feedback> (say it's a security report; leave out exploit details, and we'll reply with a private channel).

We reply within 3 working days, and tell you when it's fixed. Please give us a reasonable time to fix it before telling anyone else, and don't access other people's data, run up costs, or disrupt the service while testing.

## Supported versions

Only the live site (the `main` branch) is supported.

## What we do

How the site is protected, and what's checked automatically (gitleaks, CodeQL, Dependabot, OWASP ZAP), is in [`docs/security.md`](docs/security.md) (in Chinese).
