# Classroom：老師與班級（D103）

給老師用 ListenLoop 帶全班練習聽力：建立班級、指派教材、看每位學生的進度與進步。

## 功能

| 角色   | 可以做什麼                                                                                                                                                                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 老師   | 建立班級（名稱）、取得 8 碼邀請碼與邀請連結；看學生名單、移除學生；指派教材（官方教材、內建影片、自己建立的教材），設定開始日、截止日與通關條件；看每位學生的進度、每天的分數、第 1 天到第 7 天的進步、全班最常聽錯的字、未完成名單；匯出 CSV；發布公告 |
| 學生   | 用邀請碼或連結加入（填在班上的稱呼、年齡確認）；在「我的班級」看公告與作業（截止日期、自己的進度）；一鍵套用老師的通關條件；退出班級                                                                                                                    |
| 管理員 | 在後台使用者頁手動開通班級方案（10／20／40／80／100 人），供測試                                                                                                                                                                                        |

## 老師使用流程

1. **開通班級方案**：目前由管理員在「後台 → 使用者 → 某位使用者」選人數開通。方案正式開放後，在「班級方案」頁訂閱。
2. **建立班級**：頁首「班級」→「我教的班級」→ 輸入班級名稱 →「建立」。
3. **邀請學生**：把邀請碼（例如 `K7M2Q9XA`）寫在黑板，或分享邀請連結 `/classroom/join/K7M2Q9XA`。
   - 學生登入後輸入在班上的稱呼（建議「座號＋姓名」）並確認年齡；
   - 人數到方案上限就不能再加入。
4. **指派作業**：在班級頁「指派作業」選教材、開始與截止日期、通關條件（預設「第 7 天比第 1 天進步」，或「第 7 天 80%」）。
5. **追蹤進度**：「學生進度」每份作業一個表格：
   - 每位學生在第幾天、是否通過、第 1～7 天的分數（聽寫是正確率，跟讀是平均涵蓋率）、進步幾分；
   - 下方是未完成名單和全班最常聽錯的字。
   - 「匯出 CSV」可以用 Excel 或 Google 試算表打開（UTF-8，含中文）。
6. **公告**：最多 500 字，學生在班級頁看到。

## 隱私設計

- **學生只看得到自己的資料**：班級頁不顯示同學名單或同學的進度。
- **老師只看得到班級內的練習資料**：
  - 學生的進度只能透過資料庫函式 `class_progress` 讀取，而且只限「這個班的學生」在「這個班指派的教材」上的進度；
  - 學生自己練的其他教材、練習時間、分數紀錄，老師都看不到。
- **老師看到的是學生在班上的稱呼**，不是 Email 或帳號資料。
- **未成年**：加入時要選「已滿 18 歲」或「未滿 18 歲，已取得家長或法定代理人同意」（沿用服務條款的規定）；未滿 13 歲請由老師或家長協助，不要自行建立帳號。
- 資料表都開了 row level security（`supabase/migrations/20261110040000_classroom.sql`），`npm run rls:check` 會確認公開金鑰讀不到、寫不進。

## 之後可以加的功能

1. **自動提醒**：截止前一天提醒還沒完成的學生（Email 或 LINE 通知）。
2. **作業的通關條件自動套用**：學生加入作業時自動帶入，不用按「套用」。
3. **成績冊**：每位學生跨作業的總表、學期報告 PDF。
4. **班級排行或小組挑戰**（可選、預設關閉，避免比較壓力）。
5. **老師自建教材直接指派給班級**，並且只對班上開放（不公開到教材庫）。
6. **共同老師、助教**：一個班級多位老師。
7. **學校方案**：多個班級、多位老師的管理後台、統一帳單、單一登入（Google Workspace for Education）。
8. **聽寫答案的錯誤分析**：依句子列出全班的常見錯誤，讓老師上課講解。
9. **匯入名單**：用 CSV 一次建立學生的稱呼與座號。
10. **封存班級**：學期結束後封存，保留紀錄但不能再加入（資料表已有 `archived_at`）。
