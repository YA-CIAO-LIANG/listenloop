# ListenLoop 5 分鐘產品 Demo：腳本與分鏡

> 用途：面試、比賽評審、課堂發表。錄影建議 1920×1080、瀏覽器縮放 110%，用正式站（<https://listenloop-three.vercel.app>）。
> 手機畫面用 Chrome 開發者工具的 iPhone 尺寸，或實機錄影。

## 錄影前準備

- [ ] 準備兩個帳號：**學習者**（已完成某份教材第 1 天，第 7 天可做，用測試模式或事先練好）、**管理員**。
- [ ] 學習者帳號：「我的錯字」有幾個字到期；學習進度有幾天的紀錄。
- [ ] 關掉瀏覽器通知與書籤列；系統設為淺色，最後一幕切深色。
- [ ] 麥克風權限先允許（跟讀片段）。
- [ ] 選好示範教材：一份 1 分鐘左右的官方音檔教材（例如「Platform and Delay」），以及 Sintel 影片。

## 備用素材（時間不夠時剪掉的順序）

1. 第 10 幕（學習分析）
2. 第 5 幕的 PDF 預覽
3. 第 11 幕的待審修正（保留 API 用量）

## 錄影注意

- 第 4 幕故意打錯的字選有連音的地方，講解才會出現「為什麼難聽」。
- 第 7 幕的數字以實際畫面為準，旁白跟著改。
- 不要拍到 Email 或使用者編號以外的個人資料；後台只拍總覽、用量、待審修正。
