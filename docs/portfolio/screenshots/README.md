# Portfolio screenshots

Taken from the live site with `npm run portfolio:screenshots` (Playwright; a temporary account for the signed-in pages, deleted afterwards). Each page comes in four versions: `phone` (390 px) or `laptop` (1366 px), `light` or `dark`, at 2× pixel density.

| File prefix            | Page                                               |
| ---------------------- | -------------------------------------------------- |
| `01-home-`             | Home page, signed out                              |
| `02-library-`          | The official library with its filters              |
| `03-dictation-result-` | A Day 1 dictation result, with missed words marked |
| `04-handout-`          | The bilingual handout, with highlighter marks      |
| `05-analytics-`        | Learning analytics (streak, minutes, daily chart)  |
| `06-create-`           | Creating a material                                |
| `07-admin-`            | The admin overview                                 |

The practice data in the result, handout, and analytics shots is sample data written into the browser for the screenshots, not a real learner's.
