# SEO 關鍵字表（D167）

目標使用者：台灣學生（含留學生）與需要英文聽力的上班族。每個關鍵字群組至少要有一個對應頁面，頁面之間互相連結（文章 → 教材與主題頁；主題頁與教材頁 → 相關文章）。

> **熱度是定性估計**：目前沒有 Google Ads 關鍵字規劃工具或 Search Console 的實際搜尋量資料。上線並驗證 Search Console（見 `docs/seo.md`）約 1～2 個月後，用「成效」報表的實際曝光與點閱更新這張表。

狀態：✅ 已有頁面　🟡 有頁面但可以加強　⬜ 尚未有頁面

## 下一步（依優先順序）

1. 🟡 的主題頁（旅遊、職場、生活、新聞、求職）各寫一篇文章，連到該主題的教材。
2. Search Console 有資料後，找「曝光高、點閱率低」的頁面，改寫標題與描述。
3. 「英文發音練習」可以另寫一篇專文（母音、子音、重音），和跟讀文章互相連結。
4. 季節性：學測英聽、全民英檢在報名與考前月份前 1～2 個月更新文章日期與內容。
