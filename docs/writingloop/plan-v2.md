## A. 版面（WritingWorkspace）

- `components/writing/WritingWorkspace.tsx`：`summary`（一行）、`task`（完整說明）、`audio`（選填）、`children`（作答區）。
- 高度 = 可見範圍底端 − 元件頂端（`visualViewport.offsetTop + height − rect.top`），捲動、縮放、鍵盤開關時重算，最小 18rem。所以作答框、字數與送出按鈕永遠在畫面內。
- `wide`（1024px）以上：左欄題目、右欄作答，兩欄各自捲動。以下：上方一行摘要（`<details>`，點開展開完整說明、評分重點，展開時最多佔一半高度並可捲動），接著聲音控制，再接作答區。

## B. 不批改

- 寫作設定 `ll-writing-settings:v1`（雲端 `writing-settings`）：`review: "ai" | "none"`、`dictation: "listen-write" | "read-zh" | "listen-zh"`。
- 不批改：存文章 → 自評表（可略過）→ 完成；完成頁有「請 AI 批改」（算當時的額度）。
- 第 7 天：兩天都有分數（AI 或自評）就比分數；否則比規則指標（字數、平均句長、用字多樣性 MATTR），三項有兩項進步算通過；週紀錄記 `basis: "metrics"`，學習分析的平均進步不算這種週。

## C. 聽寫回譯

- 句子：有 AI 批改 → 自己被改過的句子（含中文翻譯，寫作回饋多一個 `zh` 欄位，提示詞改版要重錄 eval）＋範文重點句；沒有批改 → 範文句子；自訂題目 → 只有自己的句子。每天 5～8 句，第 2～6 天輪替。
- 三種模式：聽英文寫英文（預設）、看中文寫英文（可播英文提示；沒有中文的句子改用聽寫）、聽英文寫中文（和參考翻譯比對字元，寬鬆標準，顯示參考翻譯）。
- 比對沿用 `lib/scoring`（數字寫法視為相同、螢光筆）。
- 語音：`writingSentenceAudio` server action；官方範文的句子用 `npm run writing:audio` 預先產生；自己的句子第一次練習時產生，算聲音額度；未登入又沒有快取時用瀏覽器語音。

## D. 自訂題目

- id `c-<uuid>`，存在本機 `ll-writing-custom:v1` 與雲端 `writing-custom`；只有本人看得到。
- 頁面由用戶端讀取（伺服器不知道內容）；AI 批改時把題目文字當資料一起送出。

## E. 聊天

- 每則訊息一次 AI 呼叫，同時回覆＋糾正＋片語＋生字表；總結在用戶端整理，不另外呼叫。
- 每週分鐘數依實際成本計算（`lib/plans.ts`），開始時扣，提早結束退回；`writing_chat_sessions`（新增式 migration）。
- 對話存在本機與帳號自己的文件，可刪除；檢舉時只送出被檢舉的那則 AI 回覆。
- 安全：拒絕戀愛、性、暴力、違法角色扮演；13～17 歲適齡規則；自我傷害時停止情境並提供 1925、988；本機關鍵字檢查作為備援。
