# 短影音腳本（Reels／TikTok／YouTube Shorts，10 支）

> 規格：直式 9:16、30～60 秒、全程字幕（很多人靜音看）。畫面以手機錄製網站操作為主，搭配人臉出鏡或手寫字卡。
> 每支都有：開頭 3 秒的吸睛句、分鏡（秒數、畫面、旁白／字幕）、結尾行動呼籲（CTA）。
> 錄影素材可用 `docs/portfolio/screenshots/` 與 Demo 腳本（`docs/portfolio/demo-script.zh-Hant.md`）的畫面。
> 這批以台灣市場為主，只有中文版；國際推廣時再依同樣結構改寫英文版。

---

## 1. 「你真的聽懂了嗎？」（40 秒）

**開頭 3 秒**：「這句英文你聽得懂嗎？聽懂了，那你寫得出來嗎？」

| 秒數  | 畫面                       | 旁白／字幕                                             |
| ----- | -------------------------- | ------------------------------------------------------ |
| 0–3   | 人臉出鏡，手機播放一句英文 | 這句英文你聽得懂嗎？聽懂了，那你寫得出來嗎？           |
| 3–12  | 螢幕錄影：聽寫頁打字、送出 | 我以為我聽懂了，結果一打出來，漏了三個字。             |
| 12–22 | 結果頁：紅色刪除線與底線   | 漏掉的都是 a、the、and 這種小字——連音把它們藏起來了。  |
| 22–32 | 講解：「為什麼難聽懂」     | 現在每句聽錯，都會告訴我為什麼聽不出來。               |
| 32–40 | 字卡：ListenLoop＋網址     | 「聽得懂」和「聽清楚」差很多。免費試試看，連結在留言。 |

**CTA**：留言「聽寫」，我把練習連結傳給你。

## 2. 「7 天練一段英文」（55 秒）

**開頭 3 秒**：「我花 7 天只練一段 1 分鐘的英文，結果……」

| 秒數  | 畫面                    | 旁白／字幕                                     |
| ----- | ----------------------- | ---------------------------------------------- |
| 0–3   | 日曆動畫，7 格依序打勾  | 我花 7 天只練一段 1 分鐘的英文，結果……         |
| 3–15  | 第 1 天聽寫畫面         | 第 1 天：一句一句聽寫。正確率 62%。            |
| 15–30 | 第 3 天跟讀：念、字變色 | 第 2 到 6 天：每天跟讀，手機會聽我念對哪些字。 |
| 30–45 | 第 7 天結果：62% → 88%  | 第 7 天再聽寫一次：88%。                       |
| 45–55 | 人臉出鏡                | 進步變成數字，比「好像有變好」有動力多了。     |

**CTA**：想一起挑戰 7 天？追蹤，明天開始第 1 天。

## 3. 連音：want to → wanna（35 秒）

**開頭 3 秒**：「美國人說 wanna，但有時候不能說 wanna。」

| 秒數  | 畫面                            | 旁白／字幕                                             |
| ----- | ------------------------------- | ------------------------------------------------------ |
| 0–3   | 大字卡：wanna ✓ / wanna ✗       | 美國人說 wanna，但有時候不能說。                       |
| 3–15  | 字卡：I want to go → I wanna go | want to 後面接動詞，才會變 wanna。                     |
| 15–25 | 字卡：I want to the store ✗     | 後面接地方或東西，就不會變。going to 和 gonna 也一樣。 |
| 25–35 | 講解頁「為什麼難聽懂」截圖      | 聽寫時聽不出來的字，ListenLoop 會標出是哪種連音。      |

**CTA**：存起來，下次聽到 wanna 就不會卡住。

## 4. 連音：子音接母音（30 秒）

**開頭 3 秒**：「turn it off 為什麼聽起來像一個字？」

| 秒數  | 畫面                      | 旁白／字幕                                                           |
| ----- | ------------------------- | -------------------------------------------------------------------- |
| 0–3   | 波形動畫＋「tur-ni-toff」 | turn it off 為什麼聽起來像一個字？                                   |
| 3–18  | 三個例子字卡依序出現      | pick up → pi-kup；check it out → che-ki-tout；an apple → a-napple    |
| 18–30 | 人臉出鏡                  | 子音結尾碰到母音開頭，就會黏在一起。聽到不認識的字，試著拆成兩個字。 |

**CTA**：留言你最常聽不出來的英文，下一支幫你拆。

## 拍攝與發布注意

- 數字（62% → 88% 等）用真實練習紀錄，不要編造；不承諾分數。
- 不使用有版權的音樂與影片；背景音樂用平台的免費曲庫。
- Blender 影片片段要在畫面上標示出處與授權；YouTube 官方影片不要直接重新上傳整段，只用網站練習畫面。
- 每支片尾 1 秒放 Logo＋網址；說明欄放連結與主題標籤（#英文聽力 #學英文 #多益 #留學）。
