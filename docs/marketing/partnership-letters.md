# 合作邀請信範本

> 四種對象：補習班、家教老師、大學英文社團、海外台灣同學會。每種中文一封、英文一封（海外同學會與外籍老師常用英文）。
> 〔 〕裡的內容請換成實際資訊；寄送前確認對方的聯絡窗口，一次只寄一個人，不要大量群發。
> 主旨要具體、短；內文三段以內：你是誰、能給對方什麼、下一步多簡單。

- 每次合作記錄：對象、日期、結果、後續（建議用試算表）。
- 合作帶來的使用者，可以用專屬網址參數（例如 `?from=club-xxx`）追蹤；目前付費意願漏斗已記錄來源頁面，之後可擴充。
