# 上線第一個月的行銷計畫

> 前提：正式上線前要先完成 Google 登入正式發布、寄信服務（SMTP），否則新使用者無法用 Google 登入、收不到確認信（見 `docs/roadmap.md`）。
> 預算：以不花錢的自然流量為主；如果要投廣告，第 3 週後依數據再決定，金額由 Joe 決定。
> 素材都在 `docs/marketing/`：社群貼文 `social-posts.md`、短影音 `short-videos.md`、論壇 `forum-posts.md`、合作信 `partnership-letters.md`、Email `emails.md`、媒體資料 `press-kit.md`、部落格文章在網站 `/blog`。

## 每週計畫

### 第 0 週（上線前一週）：準備

- [ ] 完成 Google 登入正式發布、SMTP、正式站最後檢查（`verify-prod`）。
- [ ] 建立 Instagram、Threads、YouTube 帳號，個人檔案連結到網站。
- [ ] 預先拍好 5 支短影音（`short-videos.md` 的 1、2、3、5、8）、做好 10 張貼文圖。
- [ ] 準備 10 位朋友試用，請他們上線當天完成第 1 天，收集第一批真實數據與回饋。
- [ ] Google Search Console 提交 `sitemap.xml`（`/learn`、`/blog` 會被收錄）。

## 要追蹤的數據

| 數據                          | 為什麼重要           | 在哪裡看                                             |
| ----------------------------- | -------------------- | ---------------------------------------------------- |
| 每日註冊、每日活躍            | 成長的基本盤         | 後台總覽                                             |
| 註冊 → 完成第 1 天            | 第一印象是否清楚     | 操作紀錄                                             |
| 第 1、7、30 天留存            | 7 天循環是否留得住人 | 留存分析                                             |
| 完成 7 天循環的比例（依類別） | 哪些教材最有效       | 留存分析                                             |
| 錯字複習的完成率              | 回訪的理由是否有效   | 操作紀錄                                             |
| 定價頁 → 加入等候名單         | 付費意願             | 付費意願                                             |
| 背景與顏色「永久解鎖」的點擊  | 小額付費的意願       | 付費意願（來源 `color-unlock`、`background-unlock`） |
| 每則內容的點擊與註冊          | 哪個主題有效         | 網址參數＋操作紀錄                                   |
| AI 費用                       | 成本是否在預算內     | API 用量                                             |

## 不做的事

- 不買粉絲、不灌評論、不用小帳號推文；
- 不承諾分數（例如「保證多益 +100」）；
- 不在論壇硬推、不違反板規；
- 不寄沒有同意的行銷信。
