## 分工

### Joe 決定的

- 產品方向：7 天循環、「聽清楚每個字」、目標使用者是台灣學生；不走遊戲化（關閉魚缸）。
- 內容規則：只用 CC BY／公有領域素材、排除通訊社；VOA 暫停的決定。
- 服務與費用：改用 Azure for Students、每次真實 API 呼叫的額度（今晚 US$1.00）、不使用需要信用卡的服務。
- 介面驗收：聲音選單、導覽列、刪除筆記本、進度只在登入後顯示等。
- 需要本人操作的事：Supabase、Google OAuth、Azure、Vercel 環境變數、時間點校正。

### Claude 完成的

- 所有程式碼、測試、migration、文件，以及每個 PR 的說明。
- 規格沒寫到的細節，依業界做法自行決定，並記在 `docs/decisions.md`（D1～D82）。
- 實測與除錯：例如正式站「沒有接上服務」的設定診斷、「找不到句子」的連線錯誤處理、Lighthouse 找出的版面位移、axe 找出的對比問題、CSP 的網域實測。
- 官方範例教材 14 份的生成（Joe 明天審核後發布）。

## 更新方式

每完成一個里程碑：更新上方的數據（PR 數用 `gh pr list --state merged --limit 500 --json number -q length`、測試數看 `npm test` 的結果）、在里程碑表加一列，並補上該里程碑的分工。
