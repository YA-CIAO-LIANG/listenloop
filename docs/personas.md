## 任務（每一輪都一樣；D170 起是完整流程）

`usability/tasks.spec.ts` 用四種身分（訪客、免費、付費、管理員），在 iPhone 15、Pixel 7（觸控、手機 UA）與筆電（1280 px）上走完整流程：

1. 訪客第一次來：5 秒內看懂產品（量第一屏文字）→ 程度測驗 → 找到第一份教材。
2. 訪客：英文介面的首頁與教材頁；字放大到 200% 的首頁。
3. 免費：第 1 天聽寫 → 單字測驗 → 講義 → 聆聽模式。
4. 免費：第 2～6 天跟讀（第 2 天免手動模式、第 3～6 天沒有麥克風用「我念完了」）。
5. 免費：第 7 天聽寫 → 進步分享卡 → 滿意度問卷（main 有的話）。
6. 免費：錯字複習、我的額度（`/account/usage`）、我的教材資料夾。
7. 免費：用本週 2 分鐘額度建立教材，並用指令修改。
8. 付費：上傳音檔建立教材。
9. 免費：公開教材預覽 → 升級提示 → 方案頁 → 假門（加入名單）。
10. 付費：切換深色模式與背景 → 登出 → 換另一個帳號登入。
11. 日期顯示：台灣與美西時區（`page.clock`＋`timezoneId`）。
12. 管理員：後台、用量、檢舉、不受限制的建立頁。
13. 學生方案：用學校帳號登入後在方案頁看到「已認證」與學生價、打開訂閱假門、班級方案頁（2026-11-14 起）。
14. 班級：老師建立班級 → 指派作業（預設一週）→ 學生用邀請碼加入 → 學生看到作業並開始第 1 天 → 老師看到學生。
15. 留存：週一首頁的「上週學習報告」與補救卡、學習分析頁的連續天數。
16. 推薦好友：「我的額度」的邀請連結 → 朋友打開連結看到的登入頁。
17. 緊急開關：管理員開啟唯讀與維護模式，一般使用者看到的建立頁、維護頁與狀態頁（結束時復原）。
18. 方案頁：付費與免費帳號各看一次（月繳）、退款政策與服務條款。19.～20. 價格實驗分組、價格問卷（見 `usability/tasks.spec.ts`）。
19. 寫作（付費，P11）：題目庫篩選考試 → IELTS Task 2 → 第 1 天寫作與 AI 回饋 → 範例文章 → 第 2 天刻意練習 → 我的額度。
20. 寫作（免費，P12）：篩選留學生活 → 寫給教授的 Email → AI 回饋 → 首頁的今天的寫作 → 寫作錯誤本 → 方案頁的寫作列。
21. 寫作（訪客手機，P13）：篩選考試＋30 分鐘 → 學測看圖作文 → 自己評分 → 回到這一週。
22. 寫作（免費，P11，D195）：寫作設定改成「看中文寫英文」→ 第 1 天只儲存不批改 → 第 2 天聽寫回譯 → 檢查一句 → 更多練習。
23. 寫作（免費，P12，D196）：自訂題目（寫給房東的 Email）→ 第 1 天只儲存不批改 → 之後請 AI 批改。
24. 寫作（免費，P13，D197）：聊天練習，勾選未滿 18 歲 → 同學情境 → 一則有錯的訊息 → 點開「有建議」→ 提早結束看總結。
25. 寫作（免費，手機，P4，D199）：第 2 天做 2 句 → 離開再回來（第 3 句）→ 做完看結果 → 額外練習 1 句 → 重新整理後繼續 → 提早結束。
26. 寫作（訪客，P14，D202）：第 2 天第一次練習的提示 → 「檢查：很確定」寫錯 → 寫「我覺得錯在哪裡」→ 看答案 → 寫作設定的學習輔助。
27. 寫作（免費，美西時區＋深色，P12，D201）：寫作日曆 → 點前一天 → 首頁日曆切到「寫作」。
28. 寫作（付費，P11，D200）：第 2 天做完 → 額外練習寫一個用字不同的句子 → 結束後看 AI 批改 → 我的額度。
29. 寫作（訪客手機，P13，D203）：22:05 的睡前回顧提醒 → 寫出今天的句子 → 對照。
30. 寫作（訪客，P11，D203）：第 30 天邀請 → 再寫一次 → 自評 → 第 1、7、30 天比較。
31. 寫作（訪客，只用鍵盤，P6，D202）：第 2 天按 Enter 會提示選信心度 → Tab 到「檢查：很確定」→ 寫作日曆。
32. Beta 測試者（P3、P15、P8、P4、P14，台灣與美國中部時區，D212）：`/beta` 須知 → 註冊 → 程度測驗 → 第 1 天第一句 → 寫作第 1 天（多益題目）→ 帳號選單「回報問題」。
33. 新教材（訪客，P8、P1、P15，D213）：依主題練習 → 經典名篇、國高中程度 → 寫作的日常短文（日記）。
