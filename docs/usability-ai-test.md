## 怎麼跑

```bash
npm run build:e2e
USABILITY_ROUND=1 npm run usability   # 截圖與量測寫到 usability-results/round-1/（不進 git）
# 和其他工作目錄同時跑時，build:e2e 與 usability 都加上 MOCK_SUPABASE_PORT=… E2E_PORT=…
```

- 任務定義在 `usability/tasks.spec.ts`，每一步都會截圖並量測：
  - 是否超出螢幕寬度，以及造成的元素；

  - 第一屏的字數、最長段落、平均句長；
  - axe（WCAG 2.1 AA）違規。
- Claude 再看截圖，依角色判斷問題並評嚴重度。

### 三個評估重點

- **流程順暢不迷路**：
  - 中途離開、重新整理、先去做別的練習，回來都在原本那一句（T27）。
  - 完成後的三個去處在第一屏（F2）。
  - 「檢查」和「下一句」固定在作答框下方（D199）。
- **每天 20 分鐘內**：
  - 第 2～6 天約 6 句：每句寫＋檢查約 1 分 15 秒，約 8 分鐘；
  - 加上信心度（按鈕本身就是檢查，不另外花時間）和自我解釋（每組最多 2 次，約 40 秒）；
  - 錯誤本每天最多 5 題，約 3 分鐘；睡前回顧約 3 分鐘；
  - 合計約 15～17 分鐘。額外練習不算在內。
- **感覺到進步**：
  - 結果頁和前一天比較（F3）；
  - 寫作日曆看得到每天做了多少（F4）；
  - 第 30 天比較第 1、7、30 天（T32）。

### 角色出聲思考摘錄

- **國中生（P1）**：「首頁的『怎麼練』三步驟很清楚。聽寫打錯的字有標出來，還有中文，我知道哪裡錯了。」
- **高中生（P2）**：「第 2 天跟讀前有提示要關掉字幕，好。麥克風被拒時有說明怎麼辦。」
- **留學生（P3）**：「AI 生成的英文、中文標題都幫我填好了，還可以改。講義列印出來是英中對照。」
- **上班族（P4）**：「『10 分鐘內』一按就篩好，數字旁邊有份數。價格頁寫了年繳平均每月多少，也寫了怎麼取消。」
- **長輩（P5）**：「付款前有『測試模式』說明，按鈕也寫了金額，比較安心。字放大後沒有擠在一起。」
- **無障礙（P6）**：「axe 沒有違規；跟讀頁按兩次 Tab 就到播放器。中文標題現在用中文念了。」
- **英文介面（P7）**：「介面都是英文。卡片第一行英文標題、第二行中文，看得懂是什麼教材。」
